# Exercice Python 0110

This repository contains a small set of Python exercises focused on basic mathematics and problem solving.

## What the project does

The scripts in this project demonstrate simple Python functions for:

- integer division and modulo
- converting temperatures from Celsius to Fahrenheit
- calculating a final grade from several marks
- computing the area of a triangle

## Files

- `exo1.py` : computes the quotient and remainder of a division
- `exo2.py` : converts a temperature in Celsius to Fahrenheit
- `exo3.py` : calculates a final score using weighted percentages
- `exo4.py` : calculates the area of a triangle using a geometric formula
- `L2.py` : a more complete version of the exercises with validation and examples
- `L2_basique.py` : a basic version of the same exercises

## Example

Run any script with Python:

```bash
python exo1.py
python exo2.py
python exo3.py
python exo4.py
```

## Notes

These exercises are beginner-friendly and are intended to practice:

- functions
- inputs and outputs
- arithmetic operations
- conditional logic
- simple problem solving in Python
